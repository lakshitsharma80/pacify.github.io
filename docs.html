setup

Install the project

Clone the repository, move into the project directory, then install the one third-party dependency used for terminal tables.

1. Clone the repository

git clone https://github.com/your-username/pacify.git cd pacify

2. Install dependencies

pip install prettytable

Modules like smtplib, email, and pprint are part of Python's standard library.

first run

Run Pacify

Start the main entry point from the project root. On first launch, you’ll be prompted to enter your objects or contacts. After that, the main menu appears.

python main.py
+------+------------------------------------------+ | No. | Options You Have | +------+------------------------------------------+ | 1. | Remove all data from your device | | 2. | E-mail all objects | | 3. | E-mail a specific object by ID | | 4. | Edit details of an object | | 5. | Find an object by ID | +------+------------------------------------------+
shortcuts

Commands for Pacify

These shortcuts are called out in the README for faster access to common flows.

Inspect the local dataset

show all data

Prints the data stored in Data.py in table format.

Launch or close the AI model

ai --chat exit --model

Skip setup prompts or import a CSV

skip-api sk-a csv --[YOUR/FILE/PATH/NAME.csv]

CSV files should use the exact field names Name, ID, Email.

optional / NVIDIA

AI features

Pacify includes an assistant powered by a model configured in model.py. It reads the API key from API_KEY.txt and uses NVIDIA’s Integrate endpoint.

Data mode

If a prompt ends with from pacify data or pd, the runner switches into a two-step data mode. It answers using the local Data.User_data_1 dataset and states that the information came from Pacify.

Security note: data mode can expose anything stored in your local dataset to the model. Only use it with records you are comfortable revealing.

Configure your key

  1. Open API_KEY.txt in the project root.
  2. Replace none with your NVIDIA API key.
  3. Save the file before launching the AI runner.
Enter your prompt: Explain how to validate an email address in Python. exit --model
Gmail SMTP

Email setup

Email functionality currently uses Gmail SMTP. Before using it, enable 2-Step Verification on your Google account and generate an App Password under App Passwords. Use that App Password when Pacify prompts you.

Only Gmail accounts are currently supported. Internet access is required for all email features.
checklist

Requirements & notes

  • Python 3.10 or newer.
  • prettytable for terminal table formatting.
  • A Gmail account with App Password enabled for email features.
  • Restart the program after adding or clearing data.
  • Never share your App Password or commit it to version control.
  • Data.py is your local database — avoid manual edits unless you know what you’re doing.
