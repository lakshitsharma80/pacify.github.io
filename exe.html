before you run it

Know the edges.

The EXE is convenient, but the project README is clear that the source-code version is the better choice when you want the most current behavior.

  • The EXE may be outdated compared with the current code version. The release notes recommend the code version for advanced features.
  • Some AI features are not available in the EXE build yet; the README says those will be updated over time.
  • Email features require internet access and currently support Gmail only.
  • Gmail email setup requires 2-Step Verification and an App Password.
  • AI data mode can read the local Pacify dataset. Use it only with data you are comfortable sending to the configured model.
