// object & contact manager

Put your people data back in your hands.

Pacify is a lightweight Python CLI for storing, finding, editing, importing, and emailing contacts — with an optional AI layer when you need more from your local dataset.

01 / capabilities

Small surface.
Useful depth.

One focused CLI for the daily operations that usually get scattered across spreadsheets, inboxes, and half-finished scripts.

[ 01 ]

Store & find

Persist object records with a Name, ID, and Email, then retrieve any record by its unique ID.

[ 02 ]

Edit in place

Update an object's identity details without rebuilding the dataset or leaving the terminal.

[ 03 ]

Email with intent

Send a bulk email to every saved object or target a single contact by ID through Gmail SMTP.

[ 04 ]

Bring your CSV

Import rows in the expected Name, ID, Email shape and move an existing list into Pacify.

[ 05 ]

Ask the dataset

Launch the optional AI assistant and use “from pacify data” or “pd” for data-aware answers.

[ 06 ]

Stay local-first

Your records live in Data.py. Pacify keeps the core workflow inspectable, portable, and terminal-native.

02 / the ritual

Quiet tools for noisy data.

Pacify makes the command line feel less like a control room and more like a calm, repeatable ritual. Run the same small set of moves whenever your contact list needs attention.
