// about pacify

A calmer layer between
you and your data.

Pacify is a simple CLI project powered by AI that manages emails and data from the terminal. The repo turns a small set of everyday actions into a dependable local tool.

Built around the useful parts.

The project starts with a deliberately small record shape — Name, ID, Email — and grows outward into the actions that make a list valuable: finding, editing, emailing, clearing, and importing.

Its optional AI assistant is designed to stay close to the same workflow. Run it from the CLI, ask a concise question, and use the explicit “from pacify data” or “pd” suffix when a response should draw from the local dataset.

“Pacify your data chaos — one object at a time.”

Why the terminal?

The terminal is fast, scriptable, and honest about what a tool is doing. Pacify keeps the core loop visible, which is useful when data is personal and the workflow needs to remain easy to inspect.

project anatomy

Simple by design.

The README points to a compact structure: one entry point, a login/storage layer, a local data file, and a branding layer for the terminal.

pacify/
├── main.py # menu logic + operations
├── Login_page.py # input + persistent storage
├── Data.py # local database, auto-updated
└── Background.py # ASCII art + brand visuals
